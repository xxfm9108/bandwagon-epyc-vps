## EPYC + NVMe 到底提升了什么

单纯说"性能更强"没什么意义，具体差异体现在三个地方。

**磁盘读写是最大头**。老款配置是 Intel Xeon E5 加 SATA SSD，RAID-10 阵列顺序读写大概在 500MB/s 上下；换成 EPYC + NVMe 之后，实测顺序读写可以到 1GB/s 以上，IOPS 也翻了几倍。这个差距平时建个博客、挂个网站感知不强，但一旦跑数据库、Redis、消息队列这类吃 IO 的东西，差别会直接反映在响应速度上。

**并发处理能力**。EPYC 是新架构，单核性能和调度效率都比 E5 强，跑容器编排（Docker、Kubernetes）、CI 构建、n8n / Dify 这类自动化工具时不容易卡。搬瓦工的 EPYC 机型CPU 主频在 2.5GHz 左右。

**网络线路不变**。升级硬件没有动线路，DC9 依然是 CN2 GIA 回程，对国内三网的延迟和稳定性维持原样，晚高峰的表现和以前一致。

简单说：如果你只是建个静态博客，EPYC 对你影响不大，便宜的 Intel 套餐照样跑；如果你要跑数据库、AI 应用、爬虫或者多个容器服务，EPYC + NVMe 的钱花得值。
